# CodeAlpha Python Programming

This repository contains the Python projects completed during my **CodeAlpha Python Programming Internship**.

## Projects

### 1. Hangman Game
A simple command-line Hangman game where the player guesses a hidden word letter by letter.

**Features**
- Random word selection
- Limited attempts
- Win/Lose detection
- User-friendly interface

---

### 2. Simple Chatbot
A basic rule-based chatbot that responds to user input using predefined replies.

**Features**
- Interactive conversation
- Predefined responses
- Easy to understand Python logic

---

### 3. Stock Portfolio Tracker
A simple Python application to calculate the total value of a stock portfolio.

**Features**
- Accepts stock names and quantities
- Calculates total investment value
- Beginner-friendly implementation

---

## Technologies Used

- Python 3
- VS Code

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/jayrohit0310/CodeAlpha_Python_programming.git
```

2. Navigate to the project folder:

```bash
cd CodeAlpha_Python_programming
```

3. Run any project:

```bash
python filename.py
```

Example:

```bash
python Hangman_game.py
```
